# Search Keyword Performance Analysis

This project focuses on analyzing search keyword performance data.

## Project Contents

- analyse.ipynb - Jupyter Notebook for analysis
- index.html - HTML interface
- Queries.csv - Query dataset
- Queries_Cleaned.csv - Cleaned query dataset
- new_queries_dataset.csv - Search query performance dataset
- Cleaned dataset folder - Additional cleaned dataset files
- .gitignore - Files excluded from Git tracking
